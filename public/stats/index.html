    How these numbers work

    A visitor is counted once a day using an anonymous ID that changes every day, so someone who visits on three days counts three times. Totals for longer ranges add up the daily counts. Search engine bots are left out, and no cookies are used.

    Dates use Singapore time. Visits from deploy previews are kept separate from the live site.
